3. ffmpeg-Download bei der Installation
Der Installer laedt fuer die KI-Funktion das Programm ffmpeg herunter (ueber
das mitgelieferte Skript download_ffmpeg.bat). Quelle ist das oeffentliche
GitHub-Repository GyanD/codexffmpeg (ffmpeg-Builds von gyan.dev) auf github.com. Dafuer wird bei der
Installation eine Verbindung zu GitHub als externem Anbieter hergestellt. Wie
GitHub dabei technische Verbindungsdaten (z.B. die IP-Adresse) verarbeitet,
richtet sich nach der Datenschutzerklaerung von GitHub. Der Autor erhaelt
durch diesen Download keine Daten. Schlaegt der Download fehl, wird
Video-Organizer trotzdem installiert; ffmpeg kann dann von Hand nachgetragen
werden.

4. API-Schluessel
Dein eigener API-Schluessel (Anthropic bzw. Google Gemini, je Anbieter
getrennt) bleibt ausschliesslich auf deinem Rechner: entweder nur im
Arbeitsspeicher fuer die laufende Sitzung, oder - wenn du das ausdruecklich
ueber "Speichern" auswaehlst - dauerhaft im Windows-Anmeldeinformations-
Manager DEINES Rechners. Der Schluessel wird nie an den Autor uebertragen,
geloggt oder sonst irgendwohin hochgeladen; er wird nur an den jeweils
gewaehlten Anbieter gesendet, um die Anfrage zu authentifizieren.
